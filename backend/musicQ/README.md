# 음악 퀴즈 음성 파일(mp3 등) 폴더

이 폴더에 **음성 파일(mp3 등)**을 넣으면 그 문제가 자동으로 생깁니다.

## 넣는 방법

1. 아래 목록의 이름 그대로 파일을 저장합니다. 예) `난알아요.mp3`
2. 확장자는 아무거나 괜찮습니다 (.mp3 / .m4a / .ogg / .wav). 자동으로 찾습니다.
3. backend 폴더에서 아래 명령을 실행하면 반영됩니다.

   ```
   .venv/Scripts/python -m app.seed --reset
   ```

파일이 없는 항목은 문제로 만들지 않고 건너뛰므로, **구한 것부터 넣어도 됩니다.**
정답 문구를 바꾸고 싶으면 `backend/app/quiz_data.py`를 수정하세요.
