# 랭킹 도전 · 코인 시스템 — 결정 배경 (2026-08-11 확정)

> `docs/FEATURES.md`의 F4-3(랭킹 API)·F4-5(코인 시스템)이 최종 스펙입니다. 이 문서는 **왜 그렇게 정했는지** 배경과 향후 확장 아이디어를 남겨두는 참고 자료입니다.

## 1. 랭킹 방식을 이렇게 정한 이유

| 후보 | 문제점 |
|---|---|
| 전체 누적 정답률 | 사용자마다 푼 문제 수·구성이 달라 비교 불가 |
| 푼 문제 총 개수 | 실력이 아니라 활동량(접속 빈도) 측정이 됨 |
| 고정 문제 + 정답률 | 문제·정답이 공유되면 암기로 무력화됨 |
| **랭킹 전용 풀에서 랜덤 10문제** ✅ | 채택 — 공정성·구현난이도·UX 균형이 가장 좋음 |

→ "일반 퀴즈"(추억놀이터, 자유 풀이·기록 미반영)와 "랭킹 도전"(코인 소모, 랭킹 전용 풀에서 랜덤 10문제, 난이도 비율 고정, 기록 반영)을 분리.

개그(F3-4)는 주관식·대화형이라 "랜덤 10문제" 방식이 맞지 않아, 기존처럼 채점 직후 자동 반영하는 방식을 유지한다.

## 2. 랭킹 반영 제한 (코인으로 계속 도전해서 유리해지는 문제 방지)

공식 랭킹 반영은 분야별 **하루 1회**. 추가 도전(연습)은 코인만 있으면 가능하지만 공식 기록에는 반영하지 않는다. 결제로 얻은 코인이 랭킹 우위로 직결되지 않도록 하는 장치.

## 3. 리더보드 표시 인원

**MVP: 상위 5명 → 추후: 상위 10명으로 확대.** `GET /api/ranking` 응답의 limit 값만 바꾸면 되는 가벼운 확장이라 별도 이슈로 처리 가능.

## 4. 코인 지급/차감 (제안 수치)

| 이벤트 | 코인 |
|---|---|
| 나이맞히기 완료 | +20 |
| 일반 퀴즈 분야별 최초 완료 | +5 (분야당 1회) |
| 랭킹 도전 | −10 |
| 코인 충전(데모, 가상) | +100 |

## 5. 이번 프로젝트 범위 밖 — 발표자료에만 남기는 것

- 실제 결제 연동
- 코인으로 모리 의상/액세서리 구매 (예: 1990s 바람막이, 2000s 폴더폰 액세서리, 2010s 헤드폰)
- 특별 퀴즈팩 · 시대 콘텐츠 해금
- 일간/주간 시즌 랭킹
- 랭킹 전용 문제 관리 어드민 화면
- 코인 거래내역(`coin_transactions`) 테이블 — MVP는 `users.coin_balance` 컬럼만으로 충분, 내역 조회가 필요해지면 그때 추가

이 항목들은 "다시, 더 오래 즐기게 하려면?" 발표 부록 슬라이드와 발표 대본(Q&A)에서만 다룬다. 실제 코드/이슈로 만들지 않는다.

## 6. 4일 MVP 우선순위

1. **지금 구현**: `users.coin_balance`, 코인 획득/차감 로직, 랭킹 도전 API(코인 차감 → 랜덤 10문제 → 채점 → 저장), 정답 수 기준 정렬
2. **시간 남으면**: 풀이 시간 타이브레이크, 분야별 랭킹 화면, 코인 충전 버튼(가상), 하루 1회 제한
3. **추후(이번엔 안 함)**: 5번 항목 전체

핵심 서비스(나이맞히기 / 추억놀이터 / 세대별 챗봇)보다 우선순위가 낮다 — 시간이 부족하면 이 기능은 화면 UI + mock 데이터 수준으로 축소한다.
