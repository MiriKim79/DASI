# 기능 명세

확정된 요구사항만 기록한다. 미확정 항목은 각 절 하단 "미확정"에 남기고, 확정되면 옮긴다.

## 전체 흐름

```
접속 → 시작 화면(나이맞히기 유도, "쫄리면 패스하기")
     → 나이맞히기 퀴즈 (10문항, 패스 가능)
     → 결과 화면 (예상 나이 / 정신연령 / 결정적 답변 TOP3)
     → 메인 화면 (사이드바 등장: 홈/나이맞히기/추억놀이터/랭킹/피드백 + 우측상단 로그인)
     → 추억 놀이터 · 챗봇(우측하단 FAB, 팝업) · 랭킹 · 피드백
```

- 시작 화면은 나이맞히기 외 다른 메뉴를 보여주지 않는다
- 챗봇 FAB는 나이맞히기 완료/패스 이후부터 노출

---

## F1. 나이 맞히기 / 정신연령 — 1번

- 문항: 10개 (경험형 7 + 앵커 3), 실제 경험 여부(`직접 사용/경험했는가`) 중심, 단순 상식 아님
- 각 선택지에 대표 나이(age)와 가중치(weight) 부여
- 계산식: `정신연령 = Σ(대표 나이 × 가중치) / Σ(가중치)`, 반올림 1세 단위
- 결정적 답변 TOP3 함께 제공
- 검증: 10~50대+ 가상 사용자로 일치율/±2세/±3세/MAE 측정 후 가중치 튜닝
- 결과 저장: **로그인 사용자만** DB 저장. 비로그인은 결과 열람만 가능(저장 안 됨)
- 패스 가능, 패스해도 메인 진입 가능

## F2. 메인 / 추억 놀이터 — 2번

- 사이드바(메인 이후 전역): 홈 / 나이맞히기 / 추억놀이터 / 랭킹 / 피드백, 우측 상단 로그인
- 분야: 개그 / 드라마 / 영화 / 애니·만화책 / 문방구 용품·놀이 / 유행어·밈 / 먹거리 / 음악
- 개그 하위: 아재개그 / 문과 개그 / 이과 개그(컴공 개그 포함) / 세대 개그
- **진행 방식: 퀴즈형** (단, 개그는 예외 — F3 참고)
- 공통 디자인 시스템(CSS 변수) 안에서 분야별 색상/소품만 변형

## F3. 세대별 AI 챗봇 — 3번

- 진입점: **사이드바 아님**, 화면 우측 하단 원형 플로팅 버튼(FAB), 전역 위젯
- 표시: 페이지 위에 뜨는 **팝업(모달)**, 별도 라우트 페이지 아님
- 세대: 2000년대 / 2010년대 / 2020년대 (초기 버전 기준)
- 세대별 캐릭터: 세대에 맞는 패션의 캐릭터, **이미지는 미리 준비된 것을 선택**해 교체 — 메시지마다 AI로 생성하지 않음. 이미지 없으면 placeholder만 구현
- 말투: 세대별 persona를 시대/성격/말투/자주쓰는 표현/문화/기술서비스/먹거리/방송음악/시대 이후 표현 사용 금지 규칙으로 분리 관리. "ㅋㅋ/ㅎㅎ" 등 남용 금지, 일상 대화도 자연스럽게 가능해야 함
- 성격: 밝고 장난스러운 친구, "친절한 비서"가 아니라 "살짝 얄밉고 장난치는 친구"
- 대화 맥락: 현재 세션의 최근 대화 기록을 유지 (장기 메모리 불필요)
- 대화 저장: **로그인 사용자만** DB 저장, 비로그인은 세션 메모리만
- **개그 퀴즈**: 개그(F2의 개그 하위 분야) 콘텐츠는 추억놀이터에서 퀴즈로 안 풀고, 챗봇이 2번의 개그 콘텐츠 API를 가져와 챗봇 안에서 퀴즈로 출제. 점수는 랭킹에 반영(F4)
- OpenAI API Key는 반드시 백엔드(FastAPI)에서만 사용, 프론트엔드에 노출 금지

## F4. 회원 / 랭킹 / 피드백 — 4번

- 로그인/회원가입, JWT 인증
- 로그인 필수 기능: 나이맞히기 결과저장 / 챗봇 대화저장 / 랭킹참여 / 피드백작성
- 게스트 허용: 나이맞히기 퀴즈 풀이 + 결과 열람(저장은 안 됨)
- **랭킹: 분야별 분류** — 나이맞히기, 추억놀이터 각 분야, 챗봇 개그 퀴즈 점수 포함
- 친구 기능 없음
